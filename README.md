# A Quiet Sanctuary for Tama 🌿🌻

A heartfelt, interactive birthday web sanctuary created for **Aysha Siddiquea Tamanna (Tama)**.

## ✨ Features
- **Nature Canvas**: Floating green leaves, sunflower petals, and rose blossoms.
- **Audio Ambience**: Web Audio API synthesizer playing warm acoustic chord progressions.
- **Dudh Cha Station**: Calming thoughts over hot steaming milk tea.
- **The Wildflower Meadow**: Interactive Rose & Sunflower with soothing affirmations.
- **Village Greenery Walk**: Countryside tranquility with ancient trees, rain on soil (petrichor), and open fields.
- **Letters For Her Heart**:
  - Midnight Birthday Letter
  - Honoring Abu Bakkar Siddique & Rina Akter
  - When Thoughts Get Loud (Emergency Overthinking Relief)
  - The Halal Marriage Dream
- **Sincere Vows**: Mastering anger, disciplining daily routine, and standing by her side with her family.
- **Private Dynamic Vault**: 100% client-side photo storage (`localStorage`) ensuring complete privacy with zero server uploads.

## 🚀 How to Deploy (30-second free hosting)
1. Open **[app.netlify.com/drop](https://app.netlify.com/drop)** in your browser.
2. Drag and drop this folder (`Tama`) into the browser.
3. You will immediately get a live HTTPS URL to share!
